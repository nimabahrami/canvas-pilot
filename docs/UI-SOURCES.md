# UI sources and adaptations

The interface uses [Kokonut UI](https://kokonutui.com/docs), [Cult UI](https://www.cult-ui.com/docs), and [Interior](https://www.interior.dev/docs). Sources were obtained from their official registries. Licenses are preserved in `LICENSES/`.

| Local component | Official source | Application adaptations |
| --- | --- | --- |
| `kokonutui/toolbar.tsx` | https://kokonutui.com/docs/components/toolbar | Published tool dock, composed with annotation canvas and supplied tools. Intrinsic width encloses all seven tools and the drag grip, including the compact capture editor; the old parent-relative width cap is removed. |
| `kokonutui/file-upload.tsx` | https://kokonutui.com/docs/components/file-upload | Local import callback replaces the upload demo. |
| `cult/halo-button.tsx` | https://www.cult-ui.com/docs/components/halo-button | Capsule, frosted surface, focus/hover rim and Base UI button primitive. Removed demo stagger and keycaps. Hover runs the upstream multicolor gradient rim and a 420 ms surface sheen; 140 ms lift/press response. The rim stays still when idle and for reduced motion. |
| `cult/prompt-composer.tsx` | https://www.cult-ui.com/docs/components/prompt-composer | Controlled caption/note draft above the board, content-driven textarea height, one-line idle capsule and add-card action. Copy is consolidated into journal-level workflows. Removed permanent four-row/demo controls. |
| `cult/ai-blob-warp.tsx` | https://www.cult-ui.com/docs/components/ai-blob-warp | Published multicolor Paper Warp shader avatar, limited pixel budget and hidden/reduced-motion pause. The whole-journal enhancer floats at the main window’s bottom-right in a 48 px Halo Button with a 44 px orb; board bottom padding keeps the final card reachable. Its shader fills the actual avatar bounds. Hover/focus adds a small lift, a 2 px float and smoothly faster color flow; pointer movement blends with an autonomous 18-second drift through Motion springs without rerendering the journal. The shader receives its idle speed declaratively so asynchronous initialization cannot leave it frozen. Hidden/reduced-motion states stop shader animation and steering. |
| `cult/edge-blur.tsx` | https://www.cult-ui.com/docs/components/edge-blur | Published five masked backdrop layers beneath the top composer; visible only while the card board is scrolled. |
| `interior/segmented-control.tsx` | https://www.interior.dev/docs/segmented-control | Published keyboard-operated radiogroup and moving selection; capsule radius and 120 ms transition. |
| `interior/popover.tsx` | https://www.interior.dev/docs/popover | Published anchored positioning and dismissal. Persistent trigger, 180 ms opening and 150 ms closing slide/fade, focus restoration and first-input focus replace shared-layout morph. Composes floating session navigation, export and text annotation forms; its trigger uses the shared Halo Button. Session naming is an inline application form using the approved Input/Button primitives. |
| `interior/command-palette.tsx` | https://www.interior.dev/docs/command-palette | Published searchable keyboard list in the native session copy popup; faster transitions and dark surface. |
| `ui/button.tsx` | Cult Halo Button above | Re-export only. The previous command button and animation have been removed. |
| `ui/input.tsx`, `ui/dialog.tsx` | Kokonut’s declared Radix primitive family; https://www.interior.dev/docs/modal | Application compositions. Dialog motion uses Interior’s opacity/scale/y variants with a 150 ms exit; presence persists until the exit finishes. |
| `interior/surface-motion.ts` | https://www.interior.dev/docs/modal and https://www.interior.dev/docs/filter-grid | Shared reduced-motion-aware 160 ms entry / 150 ms exit. Applied to journal/draft/source/session cards, rename, model picker, caption/markup changes and notifications. Filter Grid’s removal/reflow pattern is adapted to journal deletion. |
| `electron/window-motion.cjs` | https://www.interior.dev/docs/modal | Opacity portion adapted to native window show/hide lifecycle with a completion wait and bounded failure fallback; no capture-coordinate transforms. |

Sora Variable is bundled locally from https://github.com/google/fonts/tree/main/ofl/sora under the OFL and used throughout the interface. Inter is retained only for canvas annotation text so saved layers keep their original metrics. Both licenses are included; there is no runtime font network request. Upstream MIT licenses: https://github.com/kokonut-labs/kokonutui, https://github.com/nolly-studio/cult-ui, https://github.com/ddoemonn/interior.

Application layouts, native window behavior, capture geometry, canvas paint/text wrapping, and persistence are custom application logic. Library provenance does not imply that these libraries supply a complete screenshot app. Neutral surfaces are #090909/#101010/#141414 with blue focus/source accents and the multicolor AI orb. Controls use 140–180 ms transitions and respect reduced motion.

The compact image/caption board takes its visual reference from [Google Keep's official product examples](https://workspace.google.com/products/keep/). Its layout and journal data binding are application code composed with the approved controls, not Google-sourced components. No new visual kit is introduced.

The macOS live display selector reuses the Cult Halo buttons in a floating capsule toolbar. The transparent selection surface and native nonactivating panel are application capture logic, not additional library components.

The capture caption panel composes Cult Prompt Composer/Halo buttons with the existing Kokonut annotation toolbar and Interior text editor. The composer accepts an autofocus caption label and omits optional import/enhancement actions in this narrow flow. Native selector/caption/default markup widths remain 420 px. Clicking the preview or a Halo Enlarge control explicitly opens a larger native editor, bounded to the current display; Reduce/Apply restores compact sizing. Interior Segmented Control supplies Fit/100% selection. The actual-size canvas viewport and native sizing are application logic. The caption composer sits at the lower edge with a flexible preview above it; the main utility window is unchanged.

The settings model picker composes the existing Interior Command Palette with a Cult Halo trigger; it is an application form, not a new visual kit. Export preview and prompt context rows use animated height/opacity disclosure. Automatic selection and model discovery are application logic.

Session rename retains the approved Input primitive with a single 1 px focus border and no stacked ring/shadow. Its Interior motion runs sequential 80 ms exit/entry phases to avoid overlapping title and input text.

Journal enhancement review composes the approved Dialog, Interior Segmented Control/surface motion, and Cult Halo buttons with an application textarea form. The shared Popover retains its scroll constraint during positioning. Session rows add a separate Halo delete action. Flat native chrome follows [Electron custom title bars](https://www.electronjs.org/docs/latest/tutorial/custom-title-bar); native window controls are OS components. The toolbar logo and desktop icon derive from Nima Bahrami's supplied doodle.

The capture-caption header adds a compact destination pill using Interior Popover, Cult Halo buttons, and the shared Input primitive. It searches saved session summaries or stages a new name without creating an empty session. The list and new-session form use the shared surface transitions, respect reduced motion, and fit within the existing 420 px popup.
